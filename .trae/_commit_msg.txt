fix(ci): 修复 pnpm 版本未指定报错 + 升级 Node 22 LTS 避免 Node 20 废弃

报错原文：
  1) Node 20 is being deprecated. This workflow is running with Node 24 by default ...
  2) pnpm/action-setup@v4: Error: No pnpm version is specified.
     Please specify it by one of the following ways:
       - in the GitHub Action config with the key "version"
       - in the package.json with the key "packageManager"

修复（双保险，任一方式都能让 pnpm/action-setup 成功）：
  1) package.json 新增 "packageManager": "pnpm@10.30.1"
     - 和本地实际使用的 pnpm 版本对齐（pnpm --version 输出 10.30.1）
     - corepack enable 的环境（setup-node 配置 corepack:true）会自动按此安装并锁定版本
     - pnpm/action-setup@v4 读取 packageManager 作为 fallback

  2) workflow .github/workflows/build-and-deploy-dist.yml：
     a) setup-node@v4 node-version: 22.x + corepack: true
        使用 Node 22 LTS，彻底避开 Node 20 废弃警告（不用 ACTIONS_ALLOW_USE_UNSECURE_NODE_VERSION）
     b) pnpm/action-setup@v4 显式 with.version: 10.30.1
        作为第二道保险，即使 packageManager 没读到也能按版本自安装。

本地验证：
  - pnpm build 仍能产出 dist/rup-tampermonkey.user.js 56.97 kB
  - 脚本头 @version 0.2.1 / @updateURL 指向 dist 分支 raw 地址，未受影响
